## 🌸 About Elarix

**Elarix** is a modern and responsive cosmetics website created to showcase makeup and skincare products in an elegant and user-friendly interface.

The project focuses on providing a visually appealing shopping experience where users can explore beauty and skincare products through clean layouts, product cards, and responsive design.

---

## ✨ Features

- 💄 Makeup product collection
- 🧴 Skincare product collection
- 🔍 Product browsing
- 🛍️ Product cards and details
- 🌸 Modern cosmetics-themed design
- 📱 Responsive design for different screen sizes
- ⚡ Fast and smooth user experience
- 🎨 Clean and attractive user interface
