# 💄 Elarix – Makeup & Skincare Website

Elarix is a modern and responsive cosmetics website designed to showcase makeup and skincare products in a simple, elegant, and user-friendly interface.

## ✨ Features

- 💄 Makeup product collection
- 🧴 Skincare product collection
- 🔍 Easy product browsing
- 🛍️ Product cards with details
- 📱 Responsive design for desktop and mobile
- 🎨 Clean and modern cosmetics-themed UI
- 🌸 Attractive product presentation
- ⚡ Fast and smooth user experience

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- React.js
- Vite
